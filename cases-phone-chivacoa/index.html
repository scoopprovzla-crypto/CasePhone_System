Datos

Los datos se guardan en este navegador. Usa siempre el mismo navegador y no borres sus datos de navegación. Para no depender de esta computadora, conéctate a la nube (abajo).
Tus datos están guardados en la nube (Firebase) y se ven en tiempo real desde cualquier dispositivo autorizado.

Cuando quieras empezar con tu negocio real, borra los datos de ejemplo. Se conservan tu configuración y tus cuentas (con saldo inicial en 0).

💱 Tasa del dólar (BCV)

para precios y cuentas en bolívares
Al usar una tasa manual se desactiva la actualización automática.
Cada producto puede tener su precio si paga en Bs (Productos → Editar). Este % se usa solo en los productos que no lo tienen: ej. 10 = precio en divisas + 10%, × tasa BCV. Con 0 cuestan lo mismo. Guarda con Guardar configuración.

Conectar a la nube (Firebase)

gratis · tus datos en cualquier dispositivo
  1. Crea tu proyecto en console.firebase.google.com, con Firestore Database y Authentication (correo/contraseña) y tu usuario.
  2. Copia el bloque firebaseConfig (⚙️ Configuración → General → Tus apps → </>).
  3. Pega aquí el bloque, tu correo y contraseña, y toca Conectar. Tus datos de esta computadora se suben a la nube.
  4. Si te lo pide, copia las reglas de seguridad y publícalas en Firestore → Reglas.

Nube y catálogo en vivo

Donde subiste este sistema. Se usa para el enlace de acceso de tu equipo. Guarda con Guardar configuración.

          
Pégalas en Firebase → Firestore Database → Reglas → Publicar. Cualquiera puede ver el catálogo y enviar pedidos; solo tu equipo entra al sistema y solo tú ves las finanzas.
